# Legacy Documentation

This directory preserves documentation imported with the adopted codebase. It is historical evidence, not current product documentation.

## Why it was archived

- It documents HTTP and Flask endpoints that are absent from the current stdio MCP entry point.
- It contains duplicated guides and references to an unavailable upstream repository.
- It describes speculative or unverified features as complete, production-ready, or enterprise-ready.
- It references source files, test suites, integrations, and performance results that cannot be found or reproduced in the adopted tree.

## Using this archive

Use these files as research input only. Confirm every claim against current source code, automated tests, and a real supported AutoCAD installation before restoring it to canonical documentation.

See the [document audit](document-audit.md) for the disposition of every imported document. Current project documentation starts at the [documentation index](../README.md).
